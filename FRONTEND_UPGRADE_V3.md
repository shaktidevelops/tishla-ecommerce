# Tishla Commerce Platform — Frontend Upgrade v3

This iteration moves the storefront from a basic multi-page shell toward a premium fashion-commerce experience.

## Frontend improvements
- Editorial full-width hero with primary and secondary CTAs.
- Professional utility/benefit strip.
- Circular department discovery rail for eight departments.
- Featured collection campaign grid.
- Expanded new-arrivals product merchandising.
- Wedding editorial banner.
- Occasion discovery cards.
- Surat craftsmanship / brand story panel.
- Social gallery.
- Premium newsletter CTA.
- Responsive mobile layout and drawer navigation.
- Professional Lucide icons rather than emoji as UI controls.
- Tishla wine / zari gold / ivory design language retained.

## Preview
Open `FRONTEND_PREVIEW.html` directly from the project folder for a no-build visual glimpse.
