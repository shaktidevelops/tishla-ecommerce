# Frontend V3 Checkpoint

1. Open `FRONTEND_PREVIEW.html` for a no-build visual glimpse.
2. Run `START_TISHLA_DEV.ps1` for the real Next.js application.
3. Review `/`, `/shop`, `/new-in`, a `/departments/...` page, a `/collections/...` page, and a `/products/...` page.
4. Test search/filter/sort on listing pages and Add to Bag from product cards.
5. Only after approval, commit with `GIT_PUSH_WINDOWS.ps1` or `GIT_PUSH_WINDOWS.bat`.
