# Tishla brand assets

The storefront is designed to use the supplied original raster artwork without redrawing or recreating the logo.

Place these exact supplied files in the project:

- `public/assets/tishla-logo.png` ← supplied `Transparent.png` (1024×1024 RGBA)
- `public/tishla-favicon.png` ← supplied `Round 1mb.png` (150×150 RGBA)

Do not replace these with an SVG recreation.

The original generated SVG wordmark may remain in the repository temporarily as a fallback, but it is not the primary brand asset.
